# Night Vision 1x1

[![Downloads](https://img.shields.io/badge/dynamic/json.svg?label=Downloads&url=https%3A%2F%2Fmods.factorio.com%2Fapi%2Fmods%2Fnight-vision-1x1&query=%24.downloads_count)](https://mods.factorio.com/mod/night-vision-1x1)

Shrinks Nightvision to a 1x1 equipment grid slot.

This is a reimplementation of the following prior mods:

- [Small Nightvision](https://mods.factorio.com/mod/smallNightvision) for Factorio 0.17 by MrDoomah
- [Small Nightvision Revised](https://mods.factorio.com/mod/SmallNightvisionRevived) for Factorio 0.18-1.1 by kreeg
- [Small Nightvision Reborn](https://mods.factorio.com/mod/small-nightvision) for Factorio 2.0 by Sharparam
